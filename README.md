# Money Map 🏦

A premium, high-tech financial management application built with React. Track your wealth across multiple accounts, monitor cash flow with automated running balances, and visualize your financial journey with advanced insights.

## ✨ Features

- **Premium Dashboard**: Charcoal & Neon aesthetic with Monefy-style grouped activity.
- **Smart Tracking**: Automated running balances for every account and transaction.
- **Interval Filtering**: Custom date range selection to see exactly where your money went.
- **Multi-Account Management**: Distinct tracking for Bank, Cash, and Savings.
- **Loan Management**: Professional tracking for borrowed and lent money with clear history.
- **Insights & Visuals**: Rich charts and Sankey diagrams to visualize wealth flow.
- **Backup & Sync**: Export and Import your data easily as JSON.

## 🚀 Tech Stack

- **Core**: React, Vite
- **State**: Zustand (with Persist middleware)
- **Styling**: Vanilla CSS (Premium Glassmorphism Design)
- **Icons**: Lucide-React
- **Charts**: Recharts

## 🛠️ Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
